# M811-RGB Mouse Configuration Tool

A Linux USB configuration tool for the RedDragon AATROX M811-RGB gaming mouse.
Current build are initial logic testing. Come back when the GUI ready

## Current Features

- LED mode configurations
- DPI configuration
- 8 Side buttons configurations
